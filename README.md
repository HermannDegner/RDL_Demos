# RDL Demos

RDL（関係力学言語 / Relational Dynamics Language）をベースにした実験デモ集。
ブラウザ上のビジュアルシミュレーションと、CLI / Python実験で構成される。

**GitHub Pages:** https://hermanndegner.github.io/RDL_Demos/

現在の理論基準:

- [Aporapeiron/RDL_Core](https://github.com/Aporapeiron/RDL_Core) — T0 BASE / SPEC v2.3
- [Aporapeiron/RDL_Functions](https://github.com/Aporapeiron/RDL_Functions) — Core v2.3同期のT2 Function / Translation契約

> このリポジトリには、Core v2.3同期済みの参照実装と、pre-v2.3語彙で作られた既存デモが共存している。個別デモに残る `ξ`、`H_vec`、`EFP` 等の名称は、そのまま現行Core定義を意味しない。現行の規範入口は上記RDL_Core / RDL_Functionsであり、`rdl_system/` はそれらの有限な参照実装である。

Core / Functions v2.3で守る基本境界は次の通り。

```text
raw input != RIB_B
RIB_B     != F
Function  != M_B
Function  != SILN
Function  != RIB_B
noise / uncertainty / local pressure != ξ
all E     != H
H         = ||H_vec||   # rdl_system/core では L2 を具体化として採用
legacy feedback event != canonical H
SILN is not generated by B
```

### 統合発展型

[RDL Living Field](demos/relational-ecology-lab/) は、既存デモで分かれていた要素を一つの因果ループへ統合した発展実験。

- 共通`RelationalAgent`型で動く5体のRabbitと1体のPredator
- 草・水・遮蔽と、摂取 → 枯渇 → 休眠 → 別地点再生の資源循環
- 制限された視覚と、方向が曖昧な音
- Rabbitの食・水・危険記憶と、Predatorの獲物・捕食結果記憶
- 予測差・ローカル負荷・再編を可視化するデモ固有状態
- fixed tick と seeded RNG による再現可能な実行

物理環境、個体の内部予測、観測者専用メトリクスは更新経路を分離している。
繁殖は、まずこの最小因果ループを説明可能に保つため意図的に含めていない。

Living Fieldでは現在、公開UIとapp読取を `localLoad / adaptationPressure / localLeapThreshold` へ移行済み。
歴史的な `H / xi / thetaEffective` 保存名はseeded挙動互換のため `core.mjs` 内に残るが、現行Core `H / ξ / θ` と同一視しない。
canonical sidecarは `RIB_B → F/F' → E = Δ(F,F') → unresolved H` を別経路で固定する。

## rdl_system（参照実装）

`rdl_system/core/` は現在のCore v2.3に合わせた最小参照コード。

```text
{RIB_i}
  ↓ Purpose / B
RIBSection(t)     -> F
RIBSection(t+Δ)   -> F'
                    ↓
                 E = Δ(F,F')
                    ↓ unresolved only
                  H_vec
                    ↓ H = ||H_vec||
                    H
                    ↓ H >= θ
                 M_Δ -> M_B'
```

- `Boundary`：Purpose / 境界 `B`
- `RIBSection`：有限な相互作用断面 `RIB_B` のデモ表現
- `MBNode`：`M_B` の小さな実装断面
- `HVector`：未解決mismatch `H_vec` の保持。L2ノルムをscalar `H` として返す
- `LeapEngine`：scalar `H >= θ` による再編候補
- `adaptationPressure`：**Core ξではない**デモ固有診断量

`rdl_system/functions/` はRDL_FunctionsのT2契約を最小実装する。

```text
RIB_B / F / state / function_output
              ↓ input_role
        FunctionModule
        ├ B_f / Purpose
        ├ local constraints
        ├ transform
        ├ unresolved / provenance
        └ output_role
              ↓
          finite output
```

Functionは `M_B` やSILNの別名ではない。出力身分と次段入力身分が異なる場合はadapter / action / environment interaction / 再境界化を明示する。

係数はCore必須値にせず `rdl_system/profiles/` に置く。係数探索と耐久検査は `rdl_system/experiment/` が担当する。

## rdl_village（簡易村シミュレーター）

[rdl_village/](rdl_village/) は Python の簡易村シミュレーター。外部依存なし。

```bash
python -m rdl_village 640 7
python -m rdl_village.test_regression
```

物理世界と個体予測場を分離し、tick解決を五相へ分けて同時性を保つ。
Core v2.3側にはcanonical比較境界を追加済みで、legacy実装量は次のlocal-state名へ再分類している。

```text
HVec      -> LocalLoadVector
XiPool    -> ExplorationState
BasalHeat -> BasalExplorationLoad
Boundary  -> ActionBoundary
```

旧名は固定seed回帰と既存APIのためcompatibility aliasとして残す。探索圧・退屈負荷・ローカル閾値をCore ξ/H/Bと同一視しない。

付属文書:

- `RDL_生命らしさ評価指針` — 生存を単一目的関数にせず、生命らしさを複数軸で観察する
- `破断検査` — 実装がどの条件で崩れるか、成功・失敗試行を含めて記録する

## rdl_bot（CLIチャットボット）

`rdl_bot/` はRDL語彙を利用した会話実験。現在はCore v2.3のcanonical sidecarを持ち、旧runtimeは互換経路として並走している。

```text
canonical: RIB_B -> F/F' -> Δ(F,F') -> explicit unresolved -> canonical H
legacy:    miss/deny/silence -> LegacyFeedbackLoadState -> legacy leap/correction
```

未解決入力キューは保存・再評価用途として残るが、**queue length -> theta** のlive結線は切断済み。`unresolved_input_pressure()` は診断量としてのみ残り、live compatibility hook `xi_pressure()` は0を返す。

また、legacy `miss / deny / silence` はcanonical Hを直接変更しない。canonical Hへ入るのはsame pre-update modelで形成された `Δ(F,F')` のうち、明示的にunresolvedと判定された成分だけである。

canonical H + fixed θ + explicit review + unique canonical target による再編mutation authorityは `cli_v23_authority.py` でopt-in運用できる。ここではlegacy `_decide_leap` をmutation authorityから外す。一方、default `main.py` は後方互換のためlegacy authorityを維持しており、全面cutoverはまだ行っていない。

```bash
cd rdl_bot
pip install -r requirements.txt
py main.py                 # default legacy authority
py cli_v23.py              # reviewed canonical sidecar
py cli_v23_authority.py    # opt-in canonical mutation authority
```

APIキーなしでも動作する（手動 seed 20ノード付き）。
詳細は [rdl_bot/README.md](rdl_bot/README.md) と [rdl_bot/CURRENT_v2.3.md](rdl_bot/CURRENT_v2.3.md) を参照。

## Tests

Node側の公開デモ回帰と、Python側のbot/village回帰はGitHub Actionsで実行する。

```bash
node --test tests/*.test.mjs
python -m unittest discover -s rdl_bot/tests -p "test_*.py" -v
python -m rdl_village.test_regression
```

参照Core / Functionsとv2.3 sidecarテストでは、少なくとも次を固定する。

- `RIB_B != F`
- `F / F'` はsame pre-update `M_B`で形成
- `E = Δ(F,F')`
- unresolved `H_vec` から scalar `H = ||H_vec||` を形成して θ 判定する
- resolved `E` は自動的に `H` へ入らない
- `Function != M_B / SILN / RIB_B`
- Functionは `B / input_role / output_role / unresolved / provenance` を保持する
- Functionのunresolvedをゼロ値へ潰さず、Core ξを数値出力へ変換しない
- legacy feedback eventはcanonical Hを直接変更しない
- demo-local `adaptationPressure != ξ`
- coverage / unknown / exploration stateをCore ξへ数値化しない
