# RDL Demos

RDL（関係力学言語 / Relational Dynamics Language）をベースにした実験デモ集。
ブラウザ上のビジュアルシミュレーションと、CLI / Python実験で構成される。

**GitHub Pages:** https://hermanndegner.github.io/RDL_Demos/

現在の理論基準: [Aporapeiron/RDL_Core](https://github.com/Aporapeiron/RDL_Core) — T0 BASE / SPEC v2.3

> このリポジトリには、Core v2.3同期済みの参照実装と、pre-v2.3語彙で作られた既存デモが共存している。個別デモに残る `ξ`、`H_vec`、`EFP` 等の名称は、そのまま現行Core定義を意味しない。現行の規範入口は `rdl_system/core/` と上記RDL_Coreである。

## Migration status

| 領域 | 状態 | 扱い |
|---|---|---|
| `rdl_system/core/` | **CURRENT v2.3 reference** | `RIBSection -> F/F' -> E -> unresolved H` を参照実装 |
| `rdl_system/profiles/`, `experiment/` | **CURRENT demo support** | Core定数ではない係数仮説・耐久探索 |
| `demos/*` | **mixed / migration pending** | デモ固有モデル。Core記号との同一視を順次解除 |
| `rdl_village/` | **pre-v2.3 implementation pending migration** | `ξ` 等をデモ固有状態へ再分類予定 |
| `rdl_bot/` | **pre-v2.3 implementation pending migration** | 旧EFP/ξ/H結線を再設計予定 |

Core v2.3で守る基本境界は次の通り。

```text
raw input != RIB_B
RIB_B     != F
Function  != M_B
noise / uncertainty / local pressure != ξ
all E     != H
SILN is not generated by B
```

### 統合発展型

[RDL Living Field](demos/relational-ecology-lab/) は、既存デモで分かれていた要素を一つの因果ループへ統合した発展実験。

- 共通`RelationalAgent`型で動く5体のRabbitと1体のPredator
- 草・水・遮蔽と、摂取 → 枯渇 → 休眠 → 別地点再生の資源循環
- 制限された視覚と、方向が曖昧な音
- Rabbitの食・水・危険記憶と、Predatorの獲物・捕食結果記憶
- 予測差・残留負荷・再編を可視化するデモ固有状態
- fixed tick と seeded RNG による再現可能な実行

物理環境、個体の内部予測、観測者専用メトリクスは更新経路を分離している。
繁殖は、まずこの最小因果ループを説明可能に保つため意図的に含めていない。

**注意:** Living Field内部の `xi` / `H_vec` 等は現在移行対象であり、現行Core `ξ` / `H` と自動的に同一ではない。

## rdl_system（参照実装）

`rdl_system/core/` は現在のCore v2.3に合わせた最小参照コード。

```text
{RIB_i}
  ↓ Purpose / B
RIBSection(t)     -> F
RIBSection(t+Δ)   -> F'
                    ↓
                 E = Δ(F,F')
                    ↓ unresolved only
                    H
                    ↓ H >= θ
                 M_Δ -> M_B'
```

- `Boundary`：Purpose / 境界 `B`
- `RIBSection`：有限な相互作用断面 `RIB_B` のデモ表現
- `MBNode`：`M_B` の小さな実装断面
- `HVector`：未解決mismatchの保持
- `LeapEngine`：再編候補
- `adaptationPressure`：**Core ξではない**デモ固有診断量

係数はCore必須値にせず `rdl_system/profiles/` に置く。係数探索と耐久検査は `rdl_system/experiment/` が担当する。

## rdl_village（簡易村シミュレーター）

[rdl_village/](rdl_village/) は Python の簡易村シミュレーター。外部依存なし。

```bash
python -m rdl_village 640 7
python -m rdl_village.test_regression
```

物理世界と個体予測場を分離し、tick解決を五相へ分けて同時性を保つ。
現在はpre-v2.3語彙を含むため、`ξ`・心理負荷・探索圧などの実装変数をCore記号から分離する移行対象として扱う。

付属文書:

- `RDL_生命らしさ評価指針` — 生存を単一目的関数にせず、生命らしさを複数軸で観察する
- `破断検査` — 実装がどの条件で崩れるか、成功・失敗試行を含めて記録する

## rdl_bot（CLIチャットボット）

`rdl_bot/` はRDL語彙を利用した会話実験だが、現在は旧 `EFP / ξ / H` 世代の設計を含む **pre-v2.3実装**。
現行Coreの参照実装としては使用せず、後続の移行対象とする。

```bash
cd rdl_bot
pip install -r requirements.txt
py main.py
```

APIキーなしでも動作する（手動 seed 20ノード付き）。
詳細は [rdl_bot/README.md](rdl_bot/README.md) を参照。

## Tests

Node側の公開デモ回帰はGitHub Actionsで実行する。

```bash
node --test tests/*.test.mjs
```

参照Coreテストでは、少なくとも次を固定する。

- `RIB_B != F`
- `F / F'` はsame pre-update `M_B`で形成
- `E = Δ(F,F')`
- resolved `E` は自動的に `H` へ入らない
- demo-local `adaptationPressure != ξ`
